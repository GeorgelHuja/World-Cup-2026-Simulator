# World-Cup-2026-Simulator

A Python Monte Carlo simulator for the 2026 FIFA World Cup.

## Features

- 48-team group stage
- Elo-based team ratings
- Poisson goal simulation
- Knockout rounds and penalty shootouts
- Tournament probability estimates
- Official World-Cup knockout format

## Installation

pip install -r requirements.txt

## Usage

Open `WorldCupSIMV5.ipynb` in Jupyter Notebook or JupyterLab
and run.
